# Sales Performance Dashboard - Toko Fashion Online

## Overview
Dashboard interaktif yang dibuat menggunakan Google Looker Studio untuk menganalisis performa penjualan toko fashion online. Proyek ini mencakup alur pengolahan data transaksi (3.000+ pesanan) dari tahap pembersihan hingga visualisasi untuk memantau pendapatan, rasio kerugian, serta performa wilayah dan kategori produk.

## Data Processing & Workflow
- **Data Cleaning**: Membersihkan data mentah di Google Sheets, menangani nilai kosong (*missing values*), me-reformat tipe data transaksi, dan memvalidasi keakuratan total pesanan.
- **Data Analysis**: Menghitung total *revenue*, total *revenue loss*, serta rasio kerugian (*loss rate*) berdasarkan wilayah dan kategori.
- **Visualization**: Merancang *dashboard* interaktif di Google Looker Studio untuk pemantauan tren harian (Jan 2022 - Feb 2025).

## Tools
- Google Sheets (Data Cleaning & Preparation)
- Google Looker Studio (Data Visualization)
- GitHub (Repository & Documentation)

## Key Insights / Analysis
- **Revenue & Loss Rate**: Total pendapatan (Rp 1,53 M), total kerugian (Rp 235 Jt), total pesanan (3.000), dan persentase kerugian (15,34%).
- **Revenue vs Revenue Loss per Kota**: Identifikasi kontribusi pendapatan dan kerugian berdasarkan 20 kota teratas (Top: Medan, Manado, Depok, dll.).
- **Revenue vs Revenue Loss per Kategori**: Analisis performa produk berdasarkan kategori (Jacket, Pants, Dress, Accessories, Shirt, T-Shirt).
- **Trend Revenue Harian**: Pemantauan tren penjualan harian.
