# Sales Performance Dashboard - Toko Fashion Online

## Overview
Dashboard interaktif yang dibuat menggunakan Google Looker Studio untuk menganalisis performa penjualan toko fashion online, mencakup pendapatan, kerugian, serta kontribusi berdasarkan kategori produk dan wilayah.

## Tools
- Google Looker Studio
- Google Sheets
- Spreadsheet
- GitHub

## Analysis
- **Revenue & Loss Rate**: Total pendapatan (Rp 1,53 M), total kerugian (Rp 235 Jt), total pesanan (3.000), dan persentase kerugian (15,34%).
- **Revenue vs Revenue Loss per Kota**: Identifikasi kontribusi pendapatan dan kerugian berdasarkan 20 kota teratas (Top: Medan, Manado, Depok, dll.).
- **Revenue vs Revenue Loss per Kategori**: Analisis performa produk berdasarkan kategori (Jacket, Pants, Dress, Accessories, Shirt, T-Shirt).
- **Trend Revenue Harian**: Pemantauan tren penjualan harian dalam rentang waktu Jan 2022 - Feb 2025.
